
# trophy-Ver1

This project is designed to provide functionalities for a student trophy page. Below are the main features included in this project.

## Time table
- 11月中旬に、管理職会議でのプレゼン
- 1月にでもページを制作する
- 4月に運用が開始

- もしかしたら、学校サイトの方を優先するかもしてない。



## Features

- **Calendar**: Highlight days with recorded events, display annual schedules, and provide a notification section.
- **Customizable Widgets**: Customize pages within widgets.
- **Facility Reservation**: Reserve available classrooms and other facilities.
- **Chat**: A chat feature for communication.
- **Deletion Functionality**: Ability to delete entries or information.
- **Class Information**:
  - Grade and Class
  - Committees
  - Project-Based Learning (PBL)
  - Club Activities
  - Individual Projects
  - Research Themes
  - Goals with deadlines

- **Trophy System**:
  - Earn trophies for achievements.
  - Rankings based on the number of trophies.

- **Password Reset**: Functionality to reset passwords.
- **UUID Authentication**: Automatic handling of domains after "@".
- **Bonuses**:
  - Login bonuses
  - Rewards for various achievements

- **Self-Research**: Tools to facilitate self-research.
- **Friends' Achievements**: Display items achieved by friends.
- **Lost and Found**: A section to display lost and found items.
- **Anonymous Teacher Feedback**: A space for anonymous teacher feedback and complaints via chat.
